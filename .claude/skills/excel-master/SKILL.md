# 엑셀의 신 (excel-master)

보는 사람이 "이걸 엑셀로 만들었어?" 하고 놀라게 만드는 영업 엑셀을 만든다.
기준은 세 가지다. **3초 안에 결론이 보이고, 숫자가 틀리지 않으며, 다음 행동이 정해진다.**

## 0. 함께 쓰는 스킬과 우선순위
| 스킬 | 역할 |
|---|---|
| `mbe-excel-report-style` | 회사 보고 양식(맑은 고딕, 회색 머리글, 노랑 강조, ▲빨강). 임원·유통사 제출용 시트는 이 규칙이 최우선 |
| `xlsx` | openpyxl 편집, 수식 재계산(`recalc.py`), 수식 오류 0건 확인 |
| `mbe-weekly-sales-report` | 주간·월간 보고 문구와 액션 플랜 |
| `dataviz`, `unslop` | 엑셀과 같이 만드는 화면(HTML·아티팩트) 디자인 |

충돌하면 이 순서로 따른다. 사용자의 말 > `mbe-excel-report-style`의 회사 규칙 > 이 스킬의 임팩트 규칙.

## 1. 모드 선택
| 요청 | 모드 | 도구 |
|---|---|---|
| 부사장·임원·유통사 제출, "회사 양식", 기존 양식 수정 | **회사 양식** | openpyxl + `mbe-excel-report-style` §7 도우미 |
| "화려하게", "임팩트", 대시보드, 분석용, 내부 공유 | **임팩트** | `scripts/xlkit.py` (xlsxwriter) |
| 별말 없음 | **2-in-1(기본)** | 첫 시트 `대시보드`(임팩트) + `보고(요약)`(회사 양식) 시트를 한 파일에 |

모드와 상관없이 지키는 공통 규칙: 맑은 고딕, 마이너스는 빨간 ▲, 0은 `-`, 단위는 표마다 오른쪽 위 끝, 작성자는 시트 맨 아래 오른쪽 한 번, 파일명은 `★내용(기준일).xlsx`.

## 2. 작업 순서
1. **목적 한 줄**: 읽는 사람 + 이 파일로 내릴 결정. 첫 화면 맨 위가 그 답이다.
2. **데이터 진단**: 원본은 절대 고치지 않고 사본에서 작업한다. 기준일, 단위, 중복·결측, 합계가 원본과 맞는지 먼저 대조한다.
3. **시트 설계**: `대시보드 → 분석 → 상세 → 원데이터 → 사용설명` 순서(§3).
4. **원데이터 시트**: 입력값 열(회색 머리글)과 계산 열(하늘색 머리글)을 구분한다.
5. **수식으로 계산**: 모든 합계·달성률·신장율·구성비·순위는 수식(§6).
6. **시각화**: §4 선택표에서 목적에 맞는 요소만 고른다. 한 화면에 강조는 1~2곳.
7. **해석 문구**: `▶` 개조식 3줄. 숫자에는 비교 기준을 붙인다(전년 같은 기간, 목표 진도, 전월).
8. **검증**: `scripts/verify_xlsx.py`로 재계산·오류 0건·합계 대조·화면 렌더링(§9).
9. **전달**: 파일 + 핵심 결론 3줄 + 확인이 필요한 가정. 필요하면 카톡 보고문(`mbe-field-visit-report`)도 만든다.

## 3. 표준 시트 구조
| 시트 | 내용 |
|---|---|
| `대시보드` | KPI 카드 4~6개 → 추이 차트 + 비교 차트 → TOP/확인 필요 표 → 핵심 해석 3줄. A4 한 장 |
| `분석` | 원인·분포·이상치(산점도, 파레토, 히트맵). 결론 문장 포함 |
| 상세 시트들 | `유통별`, `매장별`, `월별추이`, `상품`, `재고` 등. 틀 고정 + 필터 + 인쇄 제목행 |
| `원데이터` | 모든 숫자의 출처. 머리글 색으로 입력/계산 구분 |
| `사용설명` | 시트 안내(하이퍼링크), 색·기호 규칙, 갱신 방법, 기준·가정 |

## 4. 무엇을 보여주려면 무엇을 쓰나
| 보여줄 것 | 쓸 요소 |
|---|---|
| 핵심 숫자 | KPI 카드(큰 숫자 26pt + 전년비 한 줄) |
| 시간 추이(전년·목표 비교) | 막대+선 콤보(당월만 노랑), 행마다 스파크라인 |
| 크기 비교·순위 | 데이터 막대, 가로 막대 |
| 증감·편차 | 파랑-흰색-빨강 색조(히트맵), 폭포 차트 |
| 목표 달성 여부 | 달성률 글자색(100%↑ 파랑 굵게, 90%↓ 빨강), 가로 막대(축 최대 120%) |
| 구성비 | 도넛(5개 이하), 누적 막대 |
| 집중도(상위 몇 개가 매출의 몇 %) | 파레토(막대+누적% 선) |
| 두 지표의 관계(할인율×판매율) | 산점도 |
| 항목별 흐름 요약 | 스파크라인(열마다 한 칸) |
| 선택에 따라 바뀌는 보고 | 드롭다운(데이터 유효성) + SUMIFS |
| 예외·확인 필요 | 빨간 ▲, 노랑 셀, 빨간 박스(회사 규칙)

**한 표에 시각 요소는 최대 2종류.** 데이터 막대+색조+아이콘+스파크라인을 전부 얹으면 아무것도 안 보인다.

## 5. 숫자·서식 규칙
- 금액(백만원): `#,##0;[Red]"▲"#,##0;"-"` / 소수 1자리 `#,##0.0;[Red]"▲"#,##0.0;"-"`. 값이 원 단위면 `#,##0,,;...`
- 신장율·증감율: `0.0%;[Red]"▲"0.0%;"-"` / 달성률·구성비·판매율: `0.0%`
- 숫자는 오른쪽 정렬(표 본문이 짧으면 가운데). 숫자를 텍스트로 저장하지 않는다.
- 색 팔레트(임팩트): 남색 `1F3864`, 중간 파랑 `2F5597`, 연한 파랑 `8EA9DB`, 하늘 `DEEBF7`, 강조 금색 `FFC000`, 노랑 `FFFF00`(진행 중인 달), 증가 파랑 `0070C0`, 감소 빨강 `FF0000`.
- 글꼴은 맑은 고딕 한 가지. 제목 20~22pt, 섹션 12pt, 본문 10pt, 주석 9pt.
- 눈금선 끔, 확대 85%, 틀 고정, 인쇄는 A4 가로(대시보드는 세로 1장)에 너비 맞춤.

## 6. 수식 규칙
- **값 복붙 금지.** 합계·비율·순위는 수식. 보고 시트 숫자는 상세·원데이터를 참조한다.
- 쓰는 함수: `SUMIFS COUNTIFS SUMPRODUCT INDEX MATCH IFERROR RANK LARGE SMALL TEXT`.
  `XLOOKUP FILTER SORT UNIQUE SEQUENCE`는 LibreOffice 검증과 모바일 호환 문제로 쓰지 않는다.
- 0으로 나누기 방지: `=IF(분모>0, 분자/분모, "")` 또는 `IFERROR`.
- 텍스트 참조에서 빈 칸이 `0`으로 보이면 `=셀&""`.
- 목표·가정 같은 숫자는 한 셀에 모아 이름을 붙이고 수식이 그 셀을 참조한다(하드코딩 금지).
- **계산된 값을 같이 저장한다.** xlsxwriter로 만든 파일은 수식 칸의 값이 비어 있어 휴대폰 미리보기에서 0으로 보인다.
  `build_sales_workbook.py`처럼 1차 빌드 → LibreOffice 재계산 → 값 수집 → 2차 빌드(값 주입) 순서로 만든다.

## 7. xlkit 사용법
```python
import sys; sys.path.insert(0, '.claude/skills/excel-master/scripts')
from xlkit import Kit, P, NF
K = Kit('out.xlsx')                                   # 2차 빌드면 Kit('out.xlsx', cached)
ws = K.sheet('대시보드', tab=P['navy'], widths=[(0,0,1.5),(1,12,12.6)])
K.title(ws, 1, 1, 12, 'MBE 영업 대시보드', '2026년 11월 5일 마감')     # style='company'면 ■ 제목 ■
K.section(ws, 4, 1, 12, 'Ⅰ. 핵심 지표', '[단위:백만원, %]')           # 단위는 표 오른쪽 위 끝
K.kpi_cards(ws, 5, 1, [dict(label='누계 매출', value="=SUM('원데이터'!$X$2:$X$101)", nf='#,##0',
                            sub="=전년비셀", sub_nf='"전년 대비 "+0.0%;[Red]"전년 대비 "-0.0%')], span=2)
last = K.table(ws, 12, 1, 헤더, 행들, [NF['m0'], NF['pct']], ['left','right'], total_last=True)
K.databar(ws, 'E14:E24'); K.threshold(ws, 'F14:F24'); K.heat(ws, 'G14:G24', 'div'); K.spark(ws, 'H14', "'원데이터'!F2:P2")
K.col_line_chart(ws, 'B11', '월별추이', 월헤더범위, [('26년', 범위)], [('25년', 범위)], [('목표', 범위)])
K.bar_chart(...); K.doughnut_chart(...); K.scatter_chart(...)
K.footer(ws, 마지막행, 12, '영업부 정병식 과장'); K.close()
```
- 완성 예제: `scripts/build_sales_workbook.py` (대시보드·유통별·월별추이·매장별·분석·원데이터·사용설명 7시트).
  `python build_sales_workbook.py --input ytd.json --out ★MBE 영업분석(11.05마감).xlsx`
- 월간 보고 가안(15시트: 회사 양식 `보고(요약)` + 대시보드·증감분석·일별·3사비교·품목·스타일·이슈·액션·검증):
  `python scripts/build_monthly_report.py --data 자료폴더 --date 2026-11-05 --out "★MBE 11월 영업실적 보고(11.05마감)_가안.xlsx"`
  헤드라인은 일일 보고서 공식 숫자, 매장 단위는 마스터 DB를 쓰고 차이는 `※ 대조` 주석으로 밝힌다. 진도 달성은 회사 기준(채널 전체 실적 ÷ 채널 진도 목표).
  같은 실행에서 `*_deck.json`(PPT용 요약)과 `*_카톡.txt`(표 없는 카톡 보고문)가 함께 만들어지고, `검증` 시트에 자동 검증 결과(통과·주의·참고)가 들어간다.
- 임원 보고 PPT 7장(표지, 핵심 요약, 유통별·월별 추이, 증감 분해, 점검, 다음 주 액션, 제안·결정 요청):
  `node scripts/build_report_deck.js 보고_deck.json "★MBE 11월 영업실적 보고(11.05마감)_임원보고_가안.pptx"` (pptxgenjs 필요, 없으면 `npm install pptxgenjs`)
- 보고 패키지 순서: 엑셀(본체) → `verify_xlsx.py`와 `xlsx` 스킬 `recalc.py`(사본에서)로 이중 검증 → PPT → 카톡 보고문. 숫자는 항상 같은 JSON에서 나온 것만 쓴다.
- 기법 모음: `scripts/recipes_demo.py` (조건부서식, 차트 5종, 드롭다운 선택형 대시보드). 더 많은 기법은 `references/recipes.md`.
- 다른 데이터(재고, 상품 등)는 예제의 시트 함수를 복사해 열 구성만 바꾼다.

## 8. 영업·재고 지표 정의 (회사 정의가 따로 있으면 그것을 따른다)
| 지표 | 계산 |
|---|---|
| 달성률 | 실적 ÷ 목표 |
| 진도달성 | 실적 ÷ (월 목표 × 오늘까지 일 목표 진도). 진행 중인 달은 이것으로 본다 |
| 신장율 | 올해 ÷ 전년 − 1 (진행 중인 달은 전년 같은 기간) |
| 구성비 | 항목 ÷ 전체 |
| 할인율 | 1 − 실판매 ÷ TAG |
| 판매율(대시보드 기준) | 판매 TAG ÷ (판매 TAG + 매장재고 현판가) |
| 판매율(입고 기준) | 판매수량 ÷ 입고수량 |
| 재고주수 | 현재고 ÷ 주평균 판매(수량 또는 금액). 60주 초과는 빨강 |
| 점당 매출 | 매출 ÷ 판매수량 |
| 객단가 | 매출 ÷ 영수건수 |
| 한 곳 집중도 | 파레토(상위 n개 누적%) |
지표를 새로 정의하면 `사용설명` 시트와 표 아래 `※` 주석에 계산식을 적는다.

## 9. 검증 체크리스트 (전달 전 필수)
1. `python scripts/verify_xlsx.py 파일.xlsx --render` → 수식 오류 0건, 시트별 PNG로 눈으로 확인.
2. **합계 대조**: 원본 합계와 파일 합계가 맞는지 확인하고, 다르면 차이와 이유를 `※ 대조` 주석으로 남긴다.
3. 렌더링 확인: 글자 잘림(###), 차트와 표 겹침, 페이지 넘김, 단위 위치, 작성자 위치.
4. 색·글꼴이 팔레트 밖으로 섞이지 않았는지, 노랑·빨강 강조가 한두 곳인지.
5. 수식 칸에 값이 저장돼 있는지(`openpyxl data_only=True`로 읽어 0이나 None이 아닌지).
6. 완성 파일은 PC `[클로드자동화]\결과\매출\<오늘날짜>\`에도 저장한다(PC 연결 시).

## 10. 하지 않는 것
3D 차트, 7조각 이상 원형, 무지개색, 병합 남발(표 본문 병합), 숫자 텍스트 저장, 하드코딩 합계, 값 붙여넣기 갱신,
시트마다 다른 글꼴, 눈금선 켠 채 인쇄, 차트 제목과 섹션 제목 중복, 근거 없는 추정 숫자.
(임팩트 모드에서는 회사 규칙이 금지한 데이터 막대·아이콘 세트·색조를 허용하되 §4 한도 안에서만 쓴다.)

## 11. 휴대폰·공유
- 수식 값이 저장돼 있어야 모바일 엑셀·미리보기에 숫자가 보인다(§6).
- 대시보드는 세로 A4 한 장에 맞추고, 핵심 숫자는 위쪽 KPI 카드에 둔다.
- 공유할 때는 `사용설명` 시트에 기준일, 데이터 출처, 갱신 방법을 적는다.
